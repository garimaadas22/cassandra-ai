Cassandra AI — Multi-Agent Emergency Hospital Routing & Triage System

Cassandra AI is an intelligent emergency healthcare routing platform designed to solve critical golden hour delays during emergency transport. Instead of routing patients purely by geographic proximity, Cassandra AI uses multi-agent telemetry analysis to match patients with facilities that have available ICU capacity, specialized care teams, and minimal wait times.

Key Features

- Dynamic Triage Agent: Evaluates vital signs, trauma severity levels, and clinical metrics to score real-time urgency.
- Capacity Intelligence Agent: Monitors local network ED availability, ICU bed count, and specialty readiness such as Cath Lab or Trauma ICU.
- Automated Dispatch Agent: Calculates an optimal routing score, reserves hospital beds instantly, and alerts receiving emergency care teams.
- Soft Clinical Pastel Dashboard: Designed with a high-contrast, modern light-mode telemetry dashboard for emergency operations.

Tech Stack

- Frontend: React (Vite)
- Styling: Tailwind CSS, Lucide Icons
- Agent Architecture Logic: Multi-agent telemetry simulation patterns aligned with AWS Bedrock and Strands Agent SDK design specifications.
